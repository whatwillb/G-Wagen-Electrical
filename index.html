How to use this site

  1. Work in order. Do not jump to torque-converter replacement first.
  2. Clear codes after each repair or cleanup step and rescan.
  3. Take notes for voltage readings, returning codes, and any live data that changes during symptoms.
  4. Use the checklists on each page so you can keep the process clean and repeatable.
